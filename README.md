🏠 Insurance Housing Risk Prediction System

AI-powered property risk assessment platform using Machine Learning,
FastAPI, React, MongoDB and JWT authentication.

🚀 Live Demo
Frontend: https://insurance-risk-ml-react.vercel.app
Backend API: https://insurance-risk-ml.onrender.com
API Docs: https://insurance-risk-ml.onrender.com/docs

✨ Features
- JWT authentication
- User registration and login
- Protected ML prediction API
- XGBoost risk prediction
- Risk percentage and category
- Illustrative insurance premium
- Feature importance
- MongoDB user storage
- React dashboard
- FastAPI REST API
- Docker deployment
- Cloud deployment

🧠 Machine Learning
- XGBoost
- Risk probability prediction
- Feature importance
- House age
- Location risk
- Roof type
- Past claims
- Property value

🏗️ Architecture
React → FastAPI → XGBoost Model
              ↓
           MongoDB

☁️ Deployment
Frontend: Vercel
Backend: Render
Database: MongoDB Atlas

⚠️ Disclaimer
This application provides a demonstration/illustrative risk assessment
and is not an actual insurance quote or underwriting decision.
